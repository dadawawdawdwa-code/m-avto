02 / The implementation

From structure to motion.

01 HTML & CSS · Layout
Landmarks and headings give each view a clear structure. CSS Grid keeps the orbit centered and stacks the layout on narrow screens.
02 SVG · Motion
Two mirrored paths draw the horizon. The same duration controls when the heading and buttons appear, so the text waits for the rays to meet.
03 JavaScript · Interaction
Canvas renders the draggable orbit. Fragment links switch views within one HTML document and support Back and Forward when browser history is available.
03 / Project notes

Motion sets the pace.

Ink Orbit is a browser experiment in movement. A sculpture responds to your gestures, and a planet’s horizon carries you from the experience into the way it was built.

Try the orbit
  1. 01 / Pointer

    Rotate the sculpture.

    Drag the orbit to turn it. Move the cursor over it for a softer tilt while the sculpture keeps spinning.

  2. 02 / Scroll

    Trace the lower rim.

    Two rays follow your scroll and meet beneath the planet. Scroll back up to see them separate.

  3. 03 / Navigation

    Explore two views.

    Home and Code share a single HTML file. Each view has its own link, so you can revisit it directly or use the browser’s Back button.
